    • 1. Scope & System Architecture

    1.1. System Identification & Boundaries
    • STK-001
      1.1.1. Autonomous Emergency Recovery STK-001

      The system shall ensure autonomous recovery to the surface in the event of mission-critical anomalies or communication loss.
    SYS-001
    1.1.1. Communication Loss Ascent SYS-001

    Upon loss of acoustic communication for more than 10.0 seconds, the system shall initiate an autonomous ascent to the surface within 15.0 seconds.
    • SUB-001
      1. Heartbeat Timeout Watchdog SUB-001

      The GNC supervisor node shall publish an emergency ascent command if no valid heartbeat message is received within 10.0 seconds.
    • TST-001
      1. Verify Communication Loss Ascent TST-001

      Verify that the vehicle transitions to autonomous ascent mode within 15.0 seconds after acoustic link termination.
